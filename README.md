# Delhi PM2.5 Forecasting

A time-series forecasting project for exploring and predicting daily PM2.5 levels in Delhi using air-pollution and weather data. The repository contains the datasets, analysis notebooks, reusable Python utilities, and model prediction results.

## Repository contents

- `data/raw/` — source air-pollution and weather datasets
- `data/processed/` — cleaned and feature-engineered daily datasets
- `notebooks/` — step-by-step analysis and forecasting notebooks
- `src/` — reusable feature engineering and time-series utilities
- `results/tables/` — model predictions and comparison results
- `requirements.txt` — Python dependencies

## Getting started

1. Clone the repository and change into its folder.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Open the notebooks in `notebooks/` with Jupyter and run them in order.

The local virtual environment and notebook checkpoint files are excluded from version control.
